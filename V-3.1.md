# Guía definitiva ampliada de implementación
## Edge-Read-Aloud-TTS-Android — v3.1

> **Base:** v3 ampliada. **Alcance adicional:** incorpora explícitamente los fragmentos y procedimientos que los documentos fuente describen para `TextSegmenter`, `TextSanitizer`, tests JVM, caché MP3, sesión WebSocket persistente, reconexión, `WordBoundaryEvent`, `CATALOG_FILENAME`, estado de deriva testeable, decoder fail-fast, locales, release y compatibilidad Android.
>
> **Regla de integración:** adaptar paquetes, tipos y firmas a las del repositorio. No sustituir una fórmula DRM/GEC existente y verificada por una variante nueva sin un fixture determinista.

## 1. Contratos definitivos

- Mantener `TextToSpeechService`, XML Views, `ExecutorService`/`Handler`, OkHttp, DataStore y `MediaExtractor`/`MediaCodec`.
- No introducir Compose, Hilt, Room, ExoPlayer, fallback offline ni migración global a coroutines.
- Los bytes del WebSocket son audio MP3 codificado; el `SynthesisCallback` recibe PCM 16-bit.
- Cada solicitud llega a una sola terminación: `done()` o `error()`, incluida cancelación y rechazo de `audioAvailable()`.
- Nunca bloquear UI, Binder, callbacks TTS ni el hilo lector de OkHttp con I/O o DataStore.
- Sanitizar antes de segmentar y antes de producir SSML; conservar espacios salvo normalización explícitamente solicitada.
- El catálogo y la caché se sustituyen de forma atómica únicamente después de validar su contenido.
- El texto, SSML, audio, cookies, MUID, token y query sensible no se escriben en logs.

1. **Fase 1 — contratos, texto y pruebas:** `TextSanitizer`, `TextSegmenter`, SSML seguro, parser de audio, terminalidad y tests JVM sin red.

## 3. Sanitización y SSML

### TextSanitizer.kt

```kotlin
package dev.experimental.edgetts

object TextSanitizer {
    fun removeIncompatibleCharacters(text: String): String {
        if (text.isEmpty()) return text
        return buildString(text.length) {
            for (char in text) {
                when (char.code) {
                    in 0..8, in 11..12, in 14..31 -> append(' ')
                    else -> append(char)
                }
            }
        }
    }

    fun normalizeSpaces(text: String): String = text.replace(Regex(" {2,}"), " ")

    fun sanitize(text: String, collapseSpaces: Boolean = false): String {
        val sanitized = removeIncompatibleCharacters(text)
        return if (collapseSpaces) normalizeSpaces(sanitized) else sanitized
    }

    fun escapeXml(raw: String): String = buildString(raw.length + 16) {
        var index = 0
        while (index < raw.length) {
            val ch = raw[index]
            val point: Int
            val width: Int
            when {
                Character.isHighSurrogate(ch) && index + 1 < raw.length && Character.isLowSurrogate(raw[index + 1]) -> {
                    point = Character.toCodePoint(ch, raw[index + 1]); width = 2
                }
                Character.isSurrogate(ch) -> { point = 0xFFFD; width = 1 }
                else -> { point = ch.code; width = 1 }
            }
            if (!isXml10CodePoint(point)) append('\uFFFD')
            else when (point) {
                '&'.code -> append("&amp;")
                '<'.code -> append("&lt;")
                '>'.code -> append("&gt;")
                '"'.code -> append("&quot;")
                '\''.code -> append("&apos;")
                else -> appendCodePoint(point)
            }
            index += width
        }
    }

    private fun isXml10CodePoint(point: Int): Boolean =
        point == 0x9 || point == 0xA || point == 0xD ||
            point in 0x20..0xD7FF || point in 0xE000..0xFFFD ||
            point in 0x10000..0x10FFFF
}
```

## 4. Segmentación UTF-8

### TextSegmenter.kt

```kotlin
package dev.experimental.edgetts

object TextSegmenter {
    const val MAX_SEGMENT_BYTES = 4096

    fun segment(text: String): List<String> = segment(text) { false }

    fun segment(text: String, isCancelled: () -> Boolean): List<String> {
        if (text.isEmpty()) return emptyList()
        val bytes = text.toByteArray(Charsets.UTF_8)
        val result = ArrayList<String>()
        var offset = 0

        while (offset < bytes.size && !isCancelled()) {
            val limit = minOf(offset + MAX_SEGMENT_BYTES, bytes.size)
            val end = if (limit == bytes.size) bytes.size else findSmartSplitPoint(bytes, offset, limit)
            check(end > offset) { "La segmentación no avanzó: $offset -> $end" }
            val part = String(bytes, offset, end - offset, Charsets.UTF_8)
            check(!part.contains('\uFFFD')) { "Corte UTF-8 inválido" }
            result += part
            offset = end
        }
        return result
    }

    private fun findSmartSplitPoint(bytes: ByteArray, start: Int, end: Int): Int {
        for (i in end - 1 downTo start + 1) {
            if (bytes[i - 1] == '\n'.code.toByte() && bytes[i] == '\n'.code.toByte()) return i + 1
        }
        for (i in end - 1 downTo start) if (bytes[i] == '\n'.code.toByte()) return i + 1
        for (i in end - 1 downTo start) {
            if (bytes[i] == ' '.code.toByte() || bytes[i] == '\t'.code.toByte()) return i + 1
        }
        return findUtf8SafeBoundary(bytes, start, end)
    }

    private fun findUtf8SafeBoundary(bytes: ByteArray, start: Int, end: Int): Int {
        var safeEnd = end
        while (safeEnd > start && isUtf8ContinuationByte(bytes[safeEnd - 1])) safeEnd--
        if (safeEnd == start) {
            // UTF-8 válido tiene unidades de 1 a 4 bytes; avanza sin partir una unidad.
            safeEnd = minOf(start + 1, bytes.size)
            while (safeEnd < bytes.size && safeEnd < end && isUtf8ContinuationByte(bytes[safeEnd])) safeEnd++
        }
        return safeEnd
    }

    private fun isUtf8ContinuationByte(value: Byte): Boolean = (value.toInt() and 0xC0) == 0x80
}
```

El objetivo es preservar contenido: `segments.joinToString("")` debe reproducir el texto sanitizado cuando no se cancela. El límite de 4096 bytes es referencia protocolaria y debe confirmarse con fixtures y el endpoint real.

## 6. Parser, Content-Type y metadata

```kotlin
data class BinaryFrame(val headers: Map<String, String>, val payload: ByteArray)

class UnexpectedResponseException(message: String) : Exception(message)

object AudioFrameParser {
    fun parseBinaryFrame(frame: ByteArray, strict: Boolean = false): BinaryFrame {
        require(frame.size >= 2) { "Frame binario truncado" }
        val headerSize = ((frame[0].toInt() and 0xFF) shl 8) or (frame[1].toInt() and 0xFF)
        require(headerSize >= 0 && headerSize + 2 <= frame.size) { "Prefijo big-endian inválido" }
        val headerText = String(frame, 2, headerSize, Charsets.UTF_8)
        val headers = headerText.split("\r\n", "\n").mapNotNull { line ->
            val separator = line.indexOf(':')
            if (separator <= 0) null else line.substring(0, separator).trim().lowercase() to line.substring(separator + 1).trim()
        }.toMap()
        val payload = frame.copyOfRange(2 + headerSize, frame.size)
        val type = headers["content-type"]?.lowercase()
        if (strict && type == null && payload.isNotEmpty()) throw UnexpectedResponseException("Audio sin Content-Type")
        if (strict && type != null && type !in setOf("audio/mpeg", "audio/mp3")) {
            throw UnexpectedResponseException("Content-Type inesperado: $type")
        }
        return BinaryFrame(headers, payload)
    }
}

data class WordBoundaryEvent(
    val offsetMs: Long,
    val durationMs: Long,
    val text: String,
    val length: Int
)
```

## 9. Caché MP3 y escritura atómica

```kotlin
class CacheRepository(private val root: java.io.File, private val maxBytes: Long) {
    private val dir = java.io.File(root, "edge_tts_mp3").also { it.mkdirs() }

    fun readMp3(key: String): ByteArray? {
        val file = java.io.File(dir, "$key.mp3")
        val bytes = runCatching { file.readBytes() }.getOrNull()
        if (bytes == null || bytes.isEmpty()) {
            runCatching { file.delete() }
            return null
        }
        runCatching { file.setLastModified(System.currentTimeMillis()) }
        return bytes
    }

    fun writeMp3(key: String, mp3: ByteArray): Boolean {
        if (mp3.isEmpty()) return false
        val target = java.io.File(dir, "$key.mp3")
        val temporary = java.io.File(dir, "$key.mp3.tmp")
        return runCatching {
            temporary.outputStream().use { it.write(mp3); it.flush() }
            check(temporary.renameTo(target)) { "No se pudo reemplazar cache MP3" }
            enforceLimit()
            true
        }.getOrElse {
            runCatching { temporary.delete() }
            false
        }
    }

    private fun enforceLimit() {
        var total = dir.listFiles { file -> file.extension == "mp3" }.orEmpty().sumOf { it.length() }
        dir.listFiles { file -> file.extension == "mp3" }.orEmpty().sortedBy { it.lastModified() }.forEach { file ->
            if (total > maxBytes && file.delete()) total -= file.length()
        }
    }
}
```

La clave debe incluir texto sanitizado, voz, locale efectivo, rate, pitch, formato y versión de protocolo; serializar campos con formato no ambiguo y aplicar SHA-256. Invalidar `.pcm` antiguos mediante una nueva versión de caché o una migración explícita.

## 10. Decoder fail-fast

El decoder existente debe conservar `MediaExtractor` + `MediaCodec`, pero añadir: rechazo de entrada vacía, límite de bytes, deadline, detección de falta de progreso tras EOS, distinción entre audio ausente/corrupto y liberación de recursos en `finally`.

```kotlin
fun decode(mp3: ByteArray, maxInputBytes: Int, deadlineMs: Long): DecodedAudio {
    require(mp3.isNotEmpty()) { "MP3 vacío" }
    require(mp3.size <= maxInputBytes) { "MP3 excede límite" }
    val deadline = android.os.SystemClock.elapsedRealtime() + deadlineMs
    var extractor: android.media.MediaExtractor? = null
    var codec: android.media.MediaCodec? = null
    try {
        extractor = android.media.MediaExtractor()
        extractor.setDataSource(ByteArrayMediaDataSource(mp3))
        val track = selectAudioTrack(extractor) ?: throw IllegalArgumentException("No hay track de audio")
        extractor.selectTrack(track)
        val format = extractor.getTrackFormat(track)
        val mime = format.getString(android.media.MediaFormat.KEY_MIME) ?: throw IllegalArgumentException("MIME ausente")
        codec = android.media.MediaCodec.createDecoderByType(mime)
        codec.configure(format, null, null, 0)
        codec.start()

        var inputEos = false
        var outputEos = false
        var stagnantAfterEos = 0
        val pcm = java.io.ByteArrayOutputStream()
        while (!outputEos) {
            if (android.os.SystemClock.elapsedRealtime() > deadline) throw java.util.concurrent.TimeoutException("Deadline decoder")
            if (!inputEos) inputEos = queueInput(codec, extractor)
            when (val output = codec.dequeueOutputBuffer(android.media.MediaCodec.BufferInfo(), 10_000)) {
                is Int -> if (output >= 0) {
                    // Copiar PCM y liberar buffer; marcar EOS cuando corresponda.
                    stagnantAfterEos = 0
                } else if (inputEos && ++stagnantAfterEos > 25) {
                    throw IllegalStateException("Decoder sin progreso después de EOS")
                }
            }
        }
        if (pcm.size() == 0) throw IllegalStateException("Audio ausente")
        return DecodedAudio(pcm.toByteArray(), /* sample rate */ 24_000)
    } finally {
        runCatching { codec?.stop() }
        runCatching { codec?.release() }
        runCatching { extractor?.release() }
    }
}
```

Completar `ByteArrayMediaDataSource`, `selectAudioTrack`, `queueInput` y extracción PCM según las firmas existentes. Cubrir con fixtures: MP3 vacío, corrupto, EOS, timeout, ausencia de progreso y liberación de recursos.

## 11. Sesión persistente y reconexión limitada

Esta subfase solo se habilita después de cancelación y contratos probados. Debe admitir un turno activo, cola terminal, invalidación por cambio de UA/Origin/token/URL/configuración, 403 con renovación de contexto y máximo un reintento controlado por segmento.

```kotlin
class PersistentWebSocketSession(
    private val client: okhttp3.OkHttpClient,
    private val requestFactory: () -> okhttp3.Request
) : AutoCloseable {
    sealed interface Event {
        data class AudioChunk(val bytes: ByteArray) : Event
        data object TurnEnded : Event
        data class Failed(val cause: Throwable) : Event
    }

    private val lock = Any()
    @Volatile private var socket: okhttp3.WebSocket? = null
    @Volatile var needsReconnect = false
        private set
    private var activeEvents: java.util.concurrent.LinkedBlockingDeque<Event>? = null

    fun beginTurn(): java.util.concurrent.LinkedBlockingDeque<Event> = synchronized(lock) {
        check(activeEvents == null) { "Ya existe un turno activo" }
        ensureConnectedLocked()
        java.util.concurrent.LinkedBlockingDeque<Event>().also { activeEvents = it }
    }

    fun onAudio(bytes: ByteArray) { activeEvents?.offer(Event.AudioChunk(bytes)) }
    fun onTurnEnd() { activeEvents?.offer(Event.TurnEnded) }

    fun onClosed(code: Int) {
        synchronized(lock) {
            if (code != 1000) needsReconnect = true
            socket = null
            activeEvents?.offer(Event.Failed(IllegalStateException("WebSocket cerrado: $code")))
        }
    }

    fun onFailure(error: Throwable) {
        synchronized(lock) {
            needsReconnect = true
            socket = null
            activeEvents?.offer(Event.Failed(error))
        }
    }

    fun finishTurn() = synchronized(lock) { activeEvents = null }

    fun cancelActiveTurn() = synchronized(lock) {
        activeEvents?.offer(Event.Failed(java.util.concurrent.CancellationException("cancelled")))
        socket?.cancel()
        socket = null
        activeEvents = null
    }

    private fun ensureConnectedLocked() {
        if (socket != null && !needsReconnect) return
        socket?.cancel()
        needsReconnect = false
        socket = client.newWebSocket(requestFactory(), listener())
    }

    private fun listener(): okhttp3.WebSocketListener = object : okhttp3.WebSocketListener() {
        override fun onFailure(ws: okhttp3.WebSocket, t: Throwable, response: okhttp3.Response?) = onFailure(t)
        override fun onClosed(ws: okhttp3.WebSocket, code: Int, reason: String) = onClosed(code)
        // parsear frames, verificar correlación y llamar onAudio/onTurnEnd.
    }

    override fun close() = cancelActiveTurn()
}
```

No enviar dos turnos concurrentes. Invalidar la sesión al cambiar configuración y cerrar en `onDestroy()`. No asumir duración infinita ni prometer reducción de handshakes sin medición.

## 15. Criterios de salida

- `./gradlew test` es reproducible y verde sin red.
- Ningún segmento supera el límite probado ni contiene UTF-8 inválido.
- Un `deliver()` fallido, cancelación, timeout o excepción termina exactamente una vez.
- `onStop()` cancela la solicitud vigente, socket, watchdog, espera, decoder y prefetch si existe.
- Un catálogo inválido no reemplaza un catálogo válido.
- La caché MP3 inválida se elimina y no se reproduce.
- La respuesta 403 puede renovar contexto como máximo una vez; no existen bucles infinitos.
- UI, Binder y el lector WebSocket no hacen I/O síncrono.
- Release minificado conserva descubrimiento del motor, catálogo y síntesis.
- Los logs no contienen secretos ni contenido sensible.

## 16. Decisiones condicionadas

- `Content-Type` estricto: no bloquear por defecto; diagnosticar y rechazar solo datos inequívocamente inválidos o incompatibles con decoder.
- Word boundaries: no activar por defecto; el framework TTS no los expone a clientes.
- WebSocket persistente: posterior a contratos y cancelación, con correlación, invalidación y reconexión limitada.
- Streaming MP3→PCM: experimental hasta probar `MediaCodec` incremental en APIs/dispositivos mínimos.
- Prefetch: posterior a scheduler cancelable, límites de memoria y pruebas de cancelación.
